# AutoComposite 開發備忘

- 使用者本機的專案位置：`C:\專案\AutoComposite`（Windows）。說明、指令範例、路徑一律以這個位置為準。
- 本機資料夾就是這裡的 `AutoComposite/` 內容（方案檔 `AutoComposite.sln` 在根目錄），不依賴 PhotoEdit 的其他部分。
- 原始碼的版本控制在 GitHub `g23722249-stack/PhotoEdit` 的 `AutoComposite/` 子資料夾。
- 主程式只能在 Windows 執行；雲端／Linux 只能建置與跑 `AutoComposite.Tests`。
