# 曙光劍姬 Aurora Blade

致敬 1986 年《夢幻戰士 Valis》風格的**原創**橫向捲軸動作遊戲。角色、名稱、劇情、美術、音樂都是原創的，沒有使用原作的任何素材。

- 單一檔案 `index.html`，直接用瀏覽器開啟就能玩，不需要安裝或建置。
- 畫面全部用 Canvas 向量即時繪製，以螢幕原生解析度（含 Retina／4K 的 devicePixelRatio）輸出，放到多大都清晰。
- 按 `H` 切換「像素模式」：先畫在 320×180 的小畫布，再用最近鄰放大，可以對照復古低解析度的樣子。
- 音樂和音效用 WebAudio 即時合成，沒有外部音檔。

## 操作

| 按鍵 | 動作 |
|---|---|
| ← → / A D | 移動 |
| K / X / 空白 / ↑ | 跳躍（按越久跳越高） |
| ↓ ＋ 跳躍 | 滑行 |
| J / Z | 斬擊，同時放出劍氣 |
| Q（或 U） | 往左閃避（無敵） |
| E（或 L） | 往右閃避（無敵） |
| P / Esc | 暫停 |
| H | 切換 HD／像素模式 |
| M | 靜音 |

手機和平板會顯示觸控按鍵。

### Xbox 手把

用 USB 或藍牙連接後，在遊戲畫面按任一鍵，瀏覽器就會偵測到手把，畫面上方會顯示「已連接 Xbox 手把」，標題畫面的操作說明也會換成手把按鍵。支援的手把會在受傷、頭目落地等時候震動。PS 等其他標準配置的手把也能用同一套按鍵。

| 按鍵 | 動作 |
|---|---|
| 左類比 / 十字鍵 | 移動 |
| A | 跳躍（按越久跳越高） |
| B，或 ↓＋A | 滑行 |
| X / RT | 斬擊 |
| LB | 往左閃避（無敵） |
| RB | 往右閃避（無敵） |
| Menu（≡） | 開始／暫停 |
| View（⧉） | 切換 HD／像素模式 |
| 按下左類比 | 靜音 |

## 內容

- 一個關卡：夜之國的廢墟街道，有斷崖、浮空平台、兩個檢查點。
- 三種敵人：追蹤的「幽光眼」、巡邏的「影兵」、發射光彈的「魔晶」。
- 閃避：按鍵代表方向，LB／Q 往左、RB／E 往右。往主角面向的方向是前衝刺（低身疾衝），往背後是後空翻（往後躍起翻一圈）。後空翻約 0.45 秒、前衝刺約 0.26 秒，期間不受任何傷害（掉進斷崖除外）；結束後有 0.3 秒冷卻，空中每次跳躍只能閃避一次。
- 道具：愛心（體力 +3）、藍色劍晶（劍氣等級最高 3 級，第 3 級放三道劍氣）。
- 頭目「影騎士 葛雷蒙」：衝刺、扇形光彈、跳躍震地三種招式，體力剩一半時加速。
