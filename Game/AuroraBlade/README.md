# 曙光劍姬 Aurora Blade

致敬 1986 年《夢幻戰士 Valis》風格的**原創**橫向捲軸動作遊戲。角色、名稱、劇情、美術、音樂都是原創的，沒有使用原作的任何素材。

- 單一檔案 `index.html`，直接用瀏覽器開啟就能玩，不需要安裝或建置。
- 畫面全部用 Canvas 向量即時繪製，以螢幕原生解析度（含 Retina／4K 的 devicePixelRatio）輸出，放到多大都清晰。
- 按 `H` 切換「像素模式」：先畫在 320×180 的小畫布，再用最近鄰放大，可以對照復古低解析度的樣子。
- 音樂和音效用 WebAudio 即時合成，沒有外部音檔。

## 主角

星見澪：九頭身的藍色長髮少女，穿水手服（外觀參考《夢幻戰士》的麻生優子，僅供個人使用）。
第一章還沒拿到曙光之劍，只能用拳腳戰鬥。畫面左上有體力條（HP）與魔力條（MP）。

- 魔力每秒自然回復 3 點，拳腳打中敵人時也會回復 4 點；魔法「星光彈」每發用 25 點。
- 藥水最多帶 5 瓶，使用後體力 +8、魔力 +40。

## 操作

| Xbox 手把 | 鍵盤 | 動作 |
|---|---|---|
| 左類比 / 十字鍵 左右 | ← → / A D | 移動 |
| ↓ | ↓ / S | 蹲下（蹲著按 X 低踢、Y 掃堂腿） |
| ↑ | ↑ / W | 往上看（按著再按 X 上衝拳、Y 昇空拳） |
| A | K / 空白 | 跳躍（按越久跳越高，沒有二段跳） |
| B，或 ↓＋A | L，或 ↓＋跳躍 | 滑行 |
| X | J | 輕拳 |
| Y | I | 重拳 |
| LB / RB | Q / E | 往左／往右閃避：往面向的方向是前衝刺，往背後是後空翻，期間無敵 |
| LT | U | 使用藥水 |
| RT | O | 魔法「星光彈」（按著 ↑ 會往斜上方發射） |
| Menu（≡） | Enter / P | 開始／暫停 |
| View（⧉） | H | 切換 HD／像素模式 |
| 按下左類比 | M | 靜音 |

鍵盤的 J、I、K、L 排成和手把 X、Y、A、B 一樣的菱形。手機和平板會顯示觸控按鍵。
用 USB 或藍牙連接手把後，在遊戲畫面按任一鍵，瀏覽器就會偵測到；支援的手把會在受傷、終結技等時候震動。

### 連段

在招式後半段按下一個鍵就會接招（輸入會先存起來，不必抓得很準）：

| 輸入 | 招式 |
|---|---|
| X | 刺拳 |
| X X | 刺拳 → 迴旋踢 |
| X X X | 刺拳 → 迴旋踢 → 旋風踢（前後各踢一次） |
| **X X Y** | 刺拳 → 迴旋踢 → **流星爆拳**：先膝撞，再踏步打出一記 10 點傷害的重拳，附帶頓格、閃光、放射光線和往前飛的拳風 |
| X Y | 刺拳 → 雙掌底 |
| Y / Y Y | 重拳 → 後旋踢 |
| 空中 X / Y | 飛踢／流星落（往斜下俯衝踢） |

連續打中會顯示連段數與 D、C、B、A、S 評價，受傷就歸零。

## 內容

- 一個關卡：夜之國的廢墟街道，有斷崖、浮空平台、兩個檢查點。
- 三種敵人：追蹤的「幽光眼」、巡邏的「影兵」、發射光彈的「魔晶」。
- 閃避：後空翻約 0.45 秒、前衝刺約 0.26 秒，期間不受任何傷害（掉進斷崖除外）；結束後有 0.3 秒冷卻，空中每次跳躍只能閃避一次。
- 道具：愛心（體力 +6）、藍色魔晶（魔力 +40）、綠色藥水（存起來用 LT 喝）。
- 頭目「影騎士 葛雷蒙」：衝刺、扇形光彈、跳躍震地三種招式，體力剩一半時加速。
