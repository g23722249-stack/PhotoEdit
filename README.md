# PhotoEdit

非破壞性照片編輯器（VB.NET、WinForms、net8.0-windows），介面使用 Aqua.Net，定位為 iPhoto.Net 的編輯模組。

- 原始照片**永不覆寫**：「存檔」存成 PhotoEdit 專案 `.pedx`（原圖＋調整、圖層、去背遮罩、用到的貼圖全部包在一個檔），下次載入可完整接續修改；舊版照片旁的 `照片檔名.pedit.json` 仍會讀取。
- 要得到合併後的圖檔請用「檔案 → 另存新檔」或「匯出」存成 PNG／JPG／BMP，預設存成 `原檔名_edited.jpg`，JPG 保留拍攝日期等 EXIF。
- 預覽用長邊 1600 的縮圖即時計算；放大檢視超過縮圖解析度時，在背景算全尺寸預覽；匯出時以原圖全尺寸計算。

## 專案結構

| 專案 | 內容 |
|---|---|
| `PhotoEdit.Core` | 編輯配方 `EditRecipe`、算圖 `ImagePipeline`、透視校正 `Perspective`、創意特效 `Creative`（局部調整、背景模糊、移軸、文字貼圖、邊框）、繪圖圖層 `DrawLayer`/`DrawGeometry`（形狀、圖說、控制點）與筆刷引擎 `DrawingRenderer`、拼貼 `CollageLayout`/`CollageRenderer`、濾鏡預設集 `Preset`、幾何換算（含畫面座標反算回原圖）與智慧構圖、直方圖、自動調整、復原紀錄、配方存取、讀檔/匯出（依 EXIF 方向轉正）。不依賴 OpenCV |
| `PhotoEdit.Vision` | 用到 OpenCV（OpenCvSharp4 4.10）的功能：YuNet 人臉偵測 `FaceDetector`（由 iPhoto.Net 的 Quartz.FaceEngine 精簡而來）、原圖處理 `SourceFix`（污點移除、降噪、人像修飾）、自動拉直 `AutoStraighten` |
| `PhotoEdit` | 主程式 `frmEditor`（Aqua.AquaForm，預設最大化）、右側分頁面板（調整／效果／人像／修補／局部／裝飾／貼圖／文字／去背／繪圖，可拖曳分隔線調整寬度）、繪圖工具列 `DrawToolStrip` 與圖示 `DrawIcons`、拼貼視窗 `frmCollage`、預覽畫布（縮放、裁切、修補筆刷）、濾鏡列、直方圖 |
| `PhotoEdit.SelfTest` | 自我測試，不需要任何 NuGet 測試套件 |

算圖順序固定：污點移除 → 降噪 → 人像修飾（以上在已轉正原圖上，由 Vision 處理）→ 旋轉/翻轉 → 透視 → 拉直 → 裁切 → 色調（白平衡、曝光、對比、亮部、暗部、褪色、飽和度、色彩濾鏡）→ 局部調整 → 背景模糊/移軸 → 暗角/顆粒 → 銳利化 → 文字貼圖 → 繪圖圖層 → 裁切形狀 → 邊框。

### 貼圖資料夾

貼圖放在方案資料夾的 `Stick\`（`C:\專案\PhotoEdit\Stick\主題\*.png`），編譯時會複製到程式資料夾的 `stick\`，程式從那裡讀。每個子資料夾是一個主題，放 PNG（建議透明背景）、GIF、BMP、JPG；檔名以 `_` 或 `cover` 開頭的視為封面，不顯示。編輯檔只記「主題\檔名」。`D:\生活剪輯\stick\` 也有一份（新增貼圖後要另外複製過去）。

### 去背模型

`PhotoEdit.Vision/Models/isnet-general-use.onnx`（178.6 MB）與 `u2net_human_seg.onnx`（176 MB），來源 [rembg releases v0.0.0](https://github.com/danielgatis/rembg/releases/tag/v0.0.0)，Apache-2.0；用 ONNX Runtime（Microsoft.ML.OnnxRuntime）執行。和人臉模型一樣不放進 git。模型下載中（檔案被占用）時可用 `dotnet build -p:SkipModelCopy=true` 編譯。

### 人臉模型

人像功能需要 `PhotoEdit.Vision/Models/face_detection_yunet_2023mar.onnx`（[OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)，Apache-2.0，約 230 KB）。`.gitignore` 排除了 `*.onnx`，所以從 GitHub 取得原始碼後要自行放入；缺檔時人像功能會停用，其他功能照常。

## 建置與測試

Aqua.Net 同時編譯 net35 與 net8；net35 版本只能用 Visual Studio 的 MSBuild 編譯。所以用 `dotnet` 指令時請直接指定專案，不要指定 `PhotoEdit.sln`：

```bash
dotnet build PhotoEdit/PhotoEdit.vbproj
```

```bash
dotnet run --project PhotoEdit.SelfTest
```

在 Visual Studio 開啟 `PhotoEdit.sln` 則可以整個方案一起建置。

啟動時可帶入照片路徑（之後 iPhoto.Net 的「編輯」按鈕就用這個方式呼叫）：

```bash
PhotoEdit/bin/Debug/net8.0-windows/PhotoEdit.exe "D:\照片\IMG_0001.jpg"
```

## 操作

| 功能 | 方式 |
|---|---|
| 新增 | 「檔案 → 新增…」或 Ctrl+N（類似小畫家「影像屬性」與 Photoshop「新增文件」）：**底色**白／黑／自訂色彩／透明；**底圖**可直接帶入一張圖（檔案、使用中影像或剪貼簿），放置方式填滿／完整顯示／延展／原尺寸置中／並排；**影像大小**選標準版面（相片 3×5、4×6…、1 吋／2 吋大頭照、A3～A5、B5、Letter、明信片、名片、螢幕解析度、IG／FB／YouTube、圖示，可切直向／橫向）、和使用中影像／剪貼簿影像／底圖相同，或自訂寬高（像素、英吋、公分、公釐，可鎖定比例）；**解析度**（像素／英吋或像素／公分，72～600 快選）會換算列印尺寸並寫進匯出的檔案；即時顯示檔案大小與預覽。存成「圖片\PhotoEdit\新影像\新影像_寬x高_日期時間.png」後開啟編輯，上次的選擇會記住 |
| 貼成新影像 | 「編輯 → 貼成新影像」或 Ctrl+V：剪貼簿的圖片（PNG 優先，保留透明）存成「圖片\PhotoEdit\剪貼簿\貼上_日期時間.png」後開啟；檔案總管複製的圖片檔則直接開啟 |
| 存檔 | Ctrl+S：存成專案 `.pedx`（第一次會問位置，預設和照片同名）；之後直接覆寫。專案是一個 zip：原圖（原封不動含 EXIF）、編輯配方（調色、裁切、文字、貼圖、繪圖圖層…）、去背遮罩、用到的貼圖與圖片；搬到別台電腦或原圖刪掉也能載入 |
| 另存新檔 | Ctrl+Shift+S：存成 `.pedx`，或 PNG／JPG／BMP。存成圖片時有圖層會先提示「會合併」；存完視窗裡的圖層仍在，可以繼續修改 |
| 匯出 | Ctrl+E：存一份合併後的 PNG（保留透明）／JPG／BMP，不改變目前的文件 |
| 載入 | Ctrl+O 或拖曳：照片或 `.pedx` 專案 |
| 複製 | 「編輯 → 複製」或 Ctrl+C：合併所有圖層（調色、裁切、邊框、文字、貼圖、繪圖）的全尺寸影像放到剪貼簿（PNG 保留透明＋一般點陣圖），畫面不變 |
| 復原 / 重做 | Ctrl+Z / Ctrl+Y（拖曳滑桿的整段過程算一步） |
| 濾鏡 | 點下方濾鏡列的縮圖；會整組替換色調與效果，不動裁切、銳利度與人像 |
| 放大檢視 | 滾輪縮放、拖曳平移、雙擊切換符合視窗 / 100%；Ctrl+0 符合視窗、Ctrl+1 100%、Ctrl+± 縮放 |
| 向左轉 / 向右轉 | Ctrl+L / Ctrl+R |
| 裁切 | Ctrl+K：拖曳畫出範圍，拖四角或四邊調整大小（固定比例時等比例）、框內拖曳移動，框內顯示輸出像素尺寸；比例有自由、原始、1:1、4:3、3:2、16:9、5:4、IG 4:5 與 1.91:1、A4、證件照 3.5×4.5 cm，「⇄ 直橫」互換；輔助線可選三分線、黃金比例、格線、對角線；形狀可裁成圓形、圓角、愛心、星形（形狀外透明，匯出預設 PNG）；可直接輸入寬×高像素；同一列可拉直（±45°）、左右轉 90°、水平／垂直翻轉。Enter 套用；Esc 取消（裁切時做的拉直、旋轉、翻轉一起還原）；裁切中按 Ctrl+Z 只退回裁切中的步驟 |
| 智慧構圖 | 裁切列的「智慧構圖」或「影像 → 智慧構圖」：臉群水平置中、眼睛在上方三分線；選比例時也會自動依臉構圖 |
| 人像 | 磨皮、臉部提亮、亮眼；開檔後自動偵測人臉，沒偵測到臉時滑桿停用 |
| 污點／雜物移除 | 「修補」分頁的修補筆刷（H）：在照片上塗抹，放開就補上；[ ] 調整筆刷大小、右鍵拖曳平移、Esc 結束。會從附近找紋理相符的區域複製並校色，找不到時才用 inpaint |
| 降噪 | 「修補」分頁：明度（顆粒狀雜訊）、色彩（彩色雜點）分開調 |
| 透視校正 | 「修補」分頁：垂直、水平；四周不會出現空白 |
| 局部調整 | 「局部」分頁：＋漸層濾鏡（在照片上從效果最強處拖到消失處，例如壓暗天空）、＋局部筆刷（塗抹要調整的區域）；各自可調曝光、對比、飽和度、色溫 |
| 背景模糊／移軸 | 「局部」分頁：背景模糊依人臉保留人物；移軸可調清楚帶位置 |
| 邊框 | 「裝飾」分頁（只有邊框）：白邊、黑邊、拍立得、圓角、底片，可調寬度；使用各種工具時邊框也會顯示 |
| 文字特效 | 「文字」分頁：多行文字、字型（含七段數字）、粗體、直排、對齊；15 種樣式預設集（標題、貼紙、霓虹、復古、可愛、字幕、標籤、漸層、彩虹、立體、鏤空、印章、外框章、浮水印、日期）；特效組：排版（字距、行距、弧形）、外框（兩層）、底色（方塊、字幕條、壓暗照片、印章框）、陰影（顏色、距離、方向、模糊、不透明度）、發光、立體、填色（單色、漸層、彩虹、圖片、照片本身）；「日期戳記」用 EXIF 拍攝日期；「插入資訊」可插入日期、相機、檔名、GPS |
| 文字與貼圖 | 「裝飾」分頁：＋文字、＋貼圖（內建 34 款向量貼圖）；在照片上點選後：拖曳本體移動、拖曳角落等比例縮放、拖曳上方圓點旋轉（Shift 每 15° 吸附）；Ctrl+滾輪縮放、Shift+滾輪旋轉；Del 刪除；可改文字、字型、大小、旋轉、顏色、粗體、陰影 |
| 貼圖小幫手 | 貼圖分頁「貼圖小幫手…」（獨立視窗，開啟時最大化）：開啟或貼上（Ctrl+V）一張排了很多貼圖的圖，依背景色自動拆成一張張（範圍＝有顏色的最大範圍，合併距離把旁邊的小裝飾併進來，依閱讀順序編號）；左邊原圖可點框選取、按兩下排除、拖曳邊緣調整、右鍵選單拆成 2～4 張（靠太近而併在一起的會自動依一般貼圖大小在最空處切開）、右鍵拖曳補畫、Del 刪除；右邊逐張選去背方式（背景色填充〔預設，眼白等被包住的同色會保留〕／AI 一般／AI 人像／不去背），用魔術棒、保留／擦除筆刷修正，可復原；最後選主題與檔名存成透明 PNG（可剪掉透明邊），主畫面自動切到該主題 |
| 貼圖 | 「貼圖」分頁：上方用「◀ 下拉選單 ▶」切換主題（附張數；「內建」34 款向量貼圖 + stick 資料夾下的各主題），把貼圖拖到照片上即可貼上（雙擊貼在中央）；之後可移動、縮放、旋轉。「重新整理」重新讀取資料夾 |
| 面板寬度 | 拖曳照片與右側面板之間的分隔線；寬度會記在 %AppData%\PhotoEdit\settings.json |
| 去背 | 「去背」分頁：自動去背（一般＝IS-Net，人像＝U²-Net；有人臉時預設人像）；魔術棒（W，游標為魔術棒）：點一下去掉相近顏色的區域，相似程度 0～100（點過再拉會調整最後一次點擊）、只選相連區域或全圖、Alt＋點一下補回、清除雜點，不必先自動去背；保留／擦除筆刷、羽化、內縮外擴；背景換成透明、純色、模糊（景深）、圖片；「檢查遮罩」以紅色顯示去掉的部分；「存成貼圖…」把主體存成透明 PNG 放進 stick\主題\；透明背景匯出 PNG。AI 遮罩在「存檔」時一起存進專案檔 |

## 規劃

**已完成**
- 基本：旋轉、翻轉、拉直、裁切、曝光、對比、亮部、暗部、色溫、色調、飽和度、銳利度、自動增強、自動白平衡、直方圖、復原/重做、前後對照、匯出 PNG／JPG／BMP、專案檔存檔與載入、複製合併影像。
- 濾鏡預設集 12 種（原色、鮮豔、日系清新、暖陽、冷調、懷舊、老照片、黑白、高反差黑白、底片、電影感、夢幻）、暗角、褪色、顆粒、色彩濾鏡。
- 放大檢視（最高 400%，背景產生全尺寸預覽）。
- 人像：磨皮、臉部提亮、亮眼、智慧構圖。
